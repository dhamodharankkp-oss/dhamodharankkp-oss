# Pi Master Challenge

Introduction.&#x20;

Pi Master Challenge is an interactive STEM learning project developed using the BBC micro:bit and Microsoft MakeCode. The project is designed to transform the learning of the mathematical constant π (Pi) from passive memorization into an engaging, hands-on experience.

### Objective

The primary objective is to create a low-cost, portable learning tool that helps users explore and remember Pi digits through simple interaction and gameplay.

### Key Features

* Interactive learning using micro:bit
* Two operational modes: Memory Mode and Shake Mode
* Motion-based input using accelerometer
* LED display-based visual feedback
* Beginner-friendly implementation using block coding

### System Overview

The system operates through button inputs and motion sensing:

* Button A is used to switch between modes
* Button B is used to start the selected mode
* Shake gesture triggers digit display in sequence

Pi digits are stored in an array and displayed progressively based on user interaction.

### Workflow

1. Initialize system and variables
2. Select mode using Button A
3. Start mode using Button B
4. Display digits or trigger interaction based on selected mode
5. Continue sequence until completion

### Applications

* Classroom STEM learning
* Makerspace activities
* Math engagement exercises
* Introductory coding projects

### Outcome

The project demonstrates how embedded systems and simple programming can be used to make abstract mathematical concepts interactive, engaging, and accessible.
